# 覆盖边界

本页列出用例表之外的场景和运行限制，不作为通过或失败的判据。依赖缺失时将相关用例标记为 Blocked。

## 无法用本地基线验证

- **OpenLab** 联邦和真实远程 DoDoc：只检查本地设置，不连接外部实例。
- **reCAPTCHA**：无真实站点端到端配置；不把本地登录成功当验证。
- **真实 SSO**：仅合成 OAuth2/OIDC/SAML；真实 IdP、生产变体、现有账户合并/关联及 `send_code` 不在覆盖中。
- **真实 SMTP**：使用 MailCatcher 或 Rails 测试收件箱，不验证生产投递。
- **真实 PayZen 后续扣款**：本地用例使用 mock 验证到期项对账；不验证真实网关后续扣款、真实网关的跨账户换卡或真实过期购物车。模拟 422 只能检查界面处理错误的行为。
- **不受支持的语言**：`zh` 不等于 `zh-CN`，`sv` 未启用；不纳入受支持语种的断言范围。受支持语言有英文回退时，应区分缺译回退与运行错误。

| 订阅与预付包 | 实时 Stripe 订阅/分期、更换 Stripe 卡、并发/重复提交和重复扣款对账、续订后再次使用额度、预付包刷卡、空间包编辑、零元分期的支付状态。 |

| 后台 CRUD | 机器及分类、空间、培训、套餐及分类、定价、价格分类及年龄段、设置、发票、优惠券、群组的增删查改全流程。 |
| 引导、翻译及移动端 | 所有受支持语言的逐页翻译、各语言下的 3DS 失败文案、完整移动端布局。 |
